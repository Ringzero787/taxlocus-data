### Changelog

- **3.0.0** (2026-09-21) — Provenance and integrity release. ADDED to state_rates, jurisdiction_rates, nexus_thresholds, taxability: `effective_date`, `source_url`, `retrieved_at`. ADDED to jurisdiction_rates: `source_key` (the stable row key — jurisdiction names are not unique: California has 57 'Unincorporated (CDTFA tax area)' rows) and `rate_type`. ADDED to marketplace_facilitator_rules: `retrieved_at`. ADDED to payroll_local_income_tax: `source`. CHANGED MEANING: payroll `as_of` is now the source document's date or the date the value last changed/was curated; it used to be the date of the weekly run. For Ohio, `geoid` is always the 4-digit Ohio MUNI code (RITA's 3-digit member code moved to `notes`). Rows are now sorted on each table's unique key. manifest.json gained dataset_version, per-file sha256/bytes/rows and per-table last_changed. This README section is generated.
